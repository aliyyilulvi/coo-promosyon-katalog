Bu panel değişiklikleri doğrudan GitHub reponuza kaydeder. Devam etmek için bir GitHub Kişisel Erişim Belirteci (Personal Access Token) girmeniz gerekiyor.

Token'ı yoksa: github.com → sağ üstteki profil fotoğrafı → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token. "repo" iznini işaretleyin. Token sadece bu tarayıcıda saklanır, başka hiçbir yere gönderilmez.
⚠️ Bu sayfanın linkini kimseyle paylaşmayın — token'ınız bu tarayıcıda saklı kalır. Değişiklik yaptıktan sonra mutlaka "Değişiklikleri Yayınla" butonuna basmalısınız, aksi halde değişiklikler kaydedilmez.
